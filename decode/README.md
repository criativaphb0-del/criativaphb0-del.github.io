# Decode — Radar de Perfis Validados (Criativa Media)

**Objetivo:** encontrar perfis com conteúdo já validado (tração real, não vaidade) para a Criativa **modelar** — extrair padrões de posicionamento, formato e narrativa e adaptar aos clientes, sem copiar.

## Estrutura
| Arquivo | Uso |
|---|---|
| `index.html` | Ferramenta web: cadastro, score automático, filtros e export CSV (dados no navegador) |
| `posicionamento-criativa.md` | Posicionamento, pilares, linhas de conteúdo e tom da Criativa |
| `playbook.md` | Como buscar, validar e modelar (passo a passo) |
| `perfis-template.csv` | Cabeçalho-base para importar perfis (mesmas colunas do export) |

## Fluxo
1. **Caçar** perfis por nicho (playbook §1)
2. **Validar** com o Score de Validação 0–100 (playbook §2)
3. **Decodificar** hooks, formatos, ofertas e posicionamento (playbook §3)
4. **Modelar** para o cliente respeitando tom do nicho (playbook §4)
5. **Testar e medir**, realimentar a ferramenta com o resultado (playbook §5)
